# ORBITAL — AI Mission Atlas

> **"See what humanity is doing in space."**

An AI-powered interactive catalog of active human space missions across Earth, Moon, and Mars.

## Quick Start

```bash
cd orbital
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- **Interactive 3D space visualization** (Three.js) — Earth, Moon, Mars with orbits, trajectories, mission dots
- **Mission Catalog** — 14 missions seeded with real public data, fully filterable
- **AI Space Analyst** — Ask questions about any mission, powered by a provider-agnostic AI layer
- **Mission Detail pages** — Full timelines, spacecraft specs, imagery, events
- **Data Provenance** — Every data point labeled OBSERVED / DERIVED / AI / ESTIMATED
- **Mission Pulse** — At-a-glance global status: Earth, Moon, Mars
- **Mission Timeline** — Chronological view of all mission events
- **Global Search** — Search by mission, spacecraft, agency, NORAD ID

## Data Sources

| Source | Used For |
|--------|----------|
| [NASA](https://api.nasa.gov) | Mission data, imagery, rover photos |
| [CelesTrak](https://celestrak.org) | Orbital elements, NORAD IDs, TLE data |
| [SatNOGS](https://db.satnogs.org) | Transmitter data, signal observations |
| [ESA](https://www.esa.int) | European mission data |

## Data Integrity

All data is labeled with its provenance:

- **OBSERVED** — Directly from a public authoritative source
- **DERIVED** — Mathematically calculated from public data
- **AI** — Generated by the AI layer from available data
- **ESTIMATED** — Approximate values based on mission parameters

**ORBITAL does not fabricate telemetry, spacecraft health data, or real-time positions.**

## Stack

- **Frontend**: Next.js 15 + React + TypeScript + Tailwind CSS
- **3D Visualization**: Three.js (no WebGL library dependency)
- **Charts**: Recharts
- **AI**: Provider-agnostic abstraction (mock by default)
  - Set `AI_PROVIDER=watsonx` to connect IBM watsonx/Granite
  - Set `AI_PROVIDER=openai` for OpenAI

## Missions Included

**Earth:** ISS, Terra, Aqua, Landsat 9  
**Moon:** Artemis II, LRO, KPLO/Danuri, Lunar Gateway  
**Mars:** Perseverance, Curiosity, MAVEN, MRO, Mars Express, ExoMars TGO, InSight (completed)

## Connecting AI Providers

Edit [`lib/ai.ts`](./lib/ai.ts) to add new providers:

```typescript
case 'watsonx': return new WatsonxProvider();
case 'openai': return new OpenAIProvider();
```

The `AIProvider` interface requires a single method:
```typescript
generateResponse(messages: AIMessage[], context: AIContext, systemPrompt: string): Promise<string>
```

## Environment Variables

```env
NASA_API_KEY=DEMO_KEY        # Get free key at api.nasa.gov
DATABASE_URL=                 # PostgreSQL URL (optional for v1)
AI_API_KEY=                   # Your AI provider key
AI_PROVIDER=mock              # mock | openai | watsonx
```

## Demo Flow

1. Open ORBITAL → See Earth, Moon, Mars with active missions
2. Click **MOON** → Camera transitions to lunar context
3. Select **ARTEMIS II** → Mission page with phases, spacecraft, AI brief
4. Click **AI ANALYST** → Ask "What is Artemis II doing?"
5. Go to **MARS** → Select **PERSEVERANCE** → Rover imagery + timeline
6. Ask "What has Perseverance been doing recently?"
7. Open **DATA SOURCES** → Show transparent data provenance
